# Kaven Docker 0.2.0

Kaven Docker is a Windows desktop manager for browsing and synchronizing
images across Docker Registry HTTP API V2 services.

## Highlights

- Manage multiple private and public Registry connections, repositories,
  tags, manifests, and reusable proxy profiles.
- Synchronize selected image tags with platform-aware manifest handling,
  bounded cache usage, cancellation, and detailed redacted logs.
- Check for updates only through the canonical `public.data.kaven.xyz`
  manifest while allowing signed installer artifacts to use independent
  download hosts.
- Verify every automatic update with the embedded Minisign public key and
  block installation while image synchronization is active.
- Store credentials in the Windows credential manager and keep one versioned
  authoritative `config.json` under the application data root.

## Upgrade notes

Existing release-candidate installations migrate `settings.json`,
`proxies.json`, and `registries.json` into `config.json` before the main window
opens. The migration is journaled and resumes after interruption. Verified
legacy files are retained under `recovery/config-v0-backup/` for manual
recovery; credential-manager entries are preserved.

## Supported platform

This release is validated for 64-bit Windows and is distributed as a per-user
NSIS installer with a separate Minisign updater signature.
